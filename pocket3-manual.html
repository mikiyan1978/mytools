H.265 と H.264 どちらを選ぶ？
H.265（HEVC）はファイルサイズが約30〜40%小さく画質も高い。Mac は Apple Silicon（M1以降）でハードウェア H.265 デコードに対応。古い Intel Mac では再生・編集が重いため H.264 が実用的。

ボタン操作リファレンス Button Controls

電源ボタンと録画ボタン、スクリーンスワイプの組み合わせで全操作が完結します。

⏻
電源ボタン
  • 長押し 2 秒 → 電源 ON / OFF
  • 短押し 1 回 → 動画 ↔ 写真 ↔ パノラマ モード切替
  • 撮影中に短押し → ジンバル方向リセット（正面に戻す）
  • ダブルタップ → 録画停止後に先頭フレームへジャンプ（プレビュー）
⏺
録画ボタン

  • 短押し（写真モード） → シャッター
  • 長押し（動画中） → スナップショット（動画継続しながら静止画保存）
  • タイムラプスモード中 → タイムラプス開始 / 停止
↑
スクリーン — 上スワイプ
  • 設定メニュー（解像度・fps・カラー・ND 等）を表示
  • 設定後は画面タップまたは下スワイプで戻る
↓
スクリーン — 下スワイプ
  • クイック設定（ND・WB・安定化モード）のショートカット
  • 設定メニューを閉じる
↔
スクリーン — 左右スワイプ
  • 撮影モードの切替（動画 → タイムラプス → スロー → パノラマ）
  • DJI Mimo アプリ接続時は追加モードも表示
👆
スクリーン — タップ
  • フォーカスポイントの変更（タップした位置にピント）
  • 顔検出 ON 中: タップした人物をロック
  • 被写体追跡（ActiveTrack）の開始
ジンバルのジョイスティック操作（拡張グリップ装着時）：上下 = チルト / 左右 = パン。DJI Mimo アプリのジョイスティックUI でもリモート操作可能。

Section 06

カラープロファイル Color Profile

Normal と D-Log M の2択。使い分けが画質を大きく左右します。

Normal
  • コントラスト・彩度が仕上がり済み
  • 撮って出しで完成、後編集不要
  • SNS 直接アップに最適
  • ダイナミックレンジは狭め
  • 空が白飛びしやすい
D-Log M
  • フラットな発色で DR を最大化
  • 後編集で色調整が大幅に効く
  • 旅行・風景・シネマ向け
  • 要: LUT または手動グレーディング
  • DJI 公式 LUT（Rec.709）を適用
設定推奨シーン編集LUT
D-Log M旅行・風景・夜景・インタビュー必須DJI 公式「D-Log M to Rec.709」
Normal日常 Vlog・アクション・SNS 直投稿不要不要（LUT 適用不可）
DJI 公式 LUT の入手: DJI 公式サイト → サポート → ダウンロード → 「D-Log M Color Transformation」をダウンロード。DaVinci Resolve では Color ページ → LUT → Open LUT Folder に配置。Final Cut Pro は Custom LUT エフェクトとして追加。
Section 07

手ブレ補正モード Stabilization

物理3軸ジンバル＋電子補正の組み合わせ。シーンに合わせて選択します。

RockSteady
電子手ブレ補正のみ。ジンバルの物理補正と併用で強力な安定化。歩き撮り・移動中に最適。クロップ量やや大。
RockSteady MAX
最大レベルの電子補正。アクション・激しい動きに対応。クロップ量が最も大きい。4K素材でも若干画角が狭くなる。
HorizonSteady
水平ライン維持を最優先。本体を傾けても画が水平を保つ。旅行・ドライブ・ウォーキングに効果的。
HorizonBalancing
水平保持しながら本体傾きに一部追従。自然な揺れを残しつつ水平崩れを防ぐ。FPV 的ルックに。
FPV モード
ジンバルをフリーに。本体の動きがそのまま映像に反映。ダイナミックな一人称視点映像向け。
OFF（固定撮影）
三脚使用時や、ジンバルアクションを使わない固定撮影時に。バッテリー消費を抑えられる。
選び方まとめ: 歩き撮り → RockSteady ／ 走る・スポーツ → RockSteady MAX ／ 旅行・風景 → HorizonSteady ／ ダイナミック映像 → FPV ／ 三脚固定 → OFF

AF（オートフォーカス）と MF（マニュアルフォーカス）を場面に応じて切り替えます。

モード操作最適シーン
顔トラッキング AF設定 → AF → 顔優先Vlog・インタビュー・自撮り。人物が画面外に出ても再検出

Section 12

取り込み・編集ワークフロー Import & Edit

Pocket 3 → MacBook Pro の最適フローです。

SD カードを抜いてカードリーダーで接続

電源 OFF 後に microSD を抜く。USB-C カードリーダー（Thunderbolt 対応品推奨）を MacBook に接続。実測 90〜100 MB/s でコピー可能。Wi-Fi 転送の 2〜3 倍速い。

外付け SSD へコピー（内蔵 SSD は温存）

4K/30fps で 1 時間≒約 58 GB。内蔵 SSD を圧迫しないよう、Samsung T7 Shield や WD My Passport SSD 等の外付け SSD（500 GB〜1 TB）に保管。

フォルダ構成で整理

例: 2025-10-01_Tokyo-Vlog / 2025-10-02_Nikko / のように日付 + 場所名で管理。DJI が生成するファイル名（DJI_0001.MP4 等）はそのまま保持。

DaVinci Resolve でプロジェクト作成

Project Settings → Master Settings → Timeline resolution を 4K (3840×2160) に。Frame rate を撮影 fps に合わせる。Color Science は DaVinci YRGB Color Managed 推奨。

D-Log M 素材に LUT を適用（D-Log M 使用時のみ）

Color ページ → ノードの最後段に LUT ノードを追加 → 「D-Log M to Rec.709」LUT を適用。Log to Display になるため Output Color Space を Rec.709 に設定。

編集・カラーグレーディング

Cut / Edit ページでカット編集 → Color ページで Lift / Gamma / Gain 調整、肌色微調整。Fairlight ページで音声正規化（ラウドネス -14 LUFS 目安 for YouTube）。

書き出し（Deliver ページ）

YouTube 向け: H.264 4K 30fps、Restrict to 50 Mbps。Instagram 向け: H.264 1080p 30fps 縦アスペクト。アーカイブ用: Apple ProRes 422（ファイル大だが高品質）。

Final Cut Pro ユーザーへ: D-Log M LUT は エフェクト → カスタム LUT として追加可能。Apple ProRes RAW には非対応（LUT はカメラ内グレーディング素材用）。
Section 13

メンテナンス Maintenance

ジンバルカメラは精密機器です。適切なケアで長く使えます。

作業頻度方法・注意
レンズ清掃撮影前後ブロワーでホコリを飛ばしてから、マイクロファイバークロスで円を描くように拭く。液体クリーナーは少量を布に付けてから
ジンバルキャリブレーション月 1 回 or 異常時設定 → ジンバル → キャリブレーション → 平らな場所に置いて実行
ファームウェア更新月 1〜2 回確認DJI Mimo アプリ起動 → Pocket 3 接続 → アップデート通知を確認
SDカード フォーマット50〜100 時間使用毎本体内フォーマット（設定 → ストレージ → フォーマット）を推奨。PC フォーマットより安定
保管時の保護カバー毎回専用保護カバーを必ず装着。ジンバルアームへの衝撃を防止
バッテリー管理長期保管時30〜60% で保管。フル充電・完全放電での長期保管は劣化の原因
ジンバルモーター部の清掃砂埃・塩害後エアダスターで優しく吹く。水洗い厳禁（防水非対応）
USB-C ポートの清掃3〜6 ヶ月毎爪楊枝 + 乾いた布でゴミを取り除く。金属片は使わない
水濡れに注意: Pocket 3 は防水・防塵非対応（IPX なし）です。雨天・海辺・プールサイドでは防水ケースまたは防水ハウジングの使用を強く推奨します。万一水に濡れた場合は即電源 OFF にし、乾燥剤（シリカゲル）とともに袋に入れて 24〜48 時間乾燥させてください。
Section 14

よくある質問 FAQ

トラブルシューティングと疑問の解決集。

録画中に突然停止する・エラーが出る

原因の多くは SDカードの書込速度不足です。

  • V30（30 MB/s）以上の規格カードを使用しているか確認
  • カードを本体内でフォーマットし直す（設定 → ストレージ → フォーマット）
  • 長時間使用で本体が過熱すると自動停止する場合がある → 風通しのよい場所で冷却
  • カードが古い・傷んでいる場合は新品に交換
映像がジャダー（カクつき）する
  • シャッタースピードが fps の 2 倍になっているか確認（180° 則）
  • 電子手ブレ補正をオフにして確認 → ジンバルの物理的な問題かを切り分け
  • 編集ソフトでの再生ジャダーは PC スペック不足の可能性 → プロキシ編集を試す
  • ファームウェアを最新版に更新する
D-Log M の映像が白っぽく見える（編集前）

D-Log M はフラットなガンマカーブで記録されているため、LUT 適用前は白っぽく眠い発色に見えます。これは正常です。

  • DaVinci Resolve / Final Cut Pro で「D-Log M to Rec.709」LUT を適用する
  • LUT は DJI 公式サイトからダウンロード（無料）
ジンバルが水平にならない・傾いて見える
  • 設定 → ジンバル → キャリブレーション を実行（平らな場所で）
  • 保護カバーが付いたままだとキャリブレーション不可。外して実行
  • 強い磁場（スピーカー・モーター付近）を避ける
  • 解決しない場合は DJI サポートに問い合わせ
DJI Mimo アプリと接続できない
  • Pocket 3 と Mimo アプリを最新バージョンに更新する
  • Bluetooth と Wi-Fi の両方を ON にした状態で接続を試みる
  • スマートフォンの Bluetooth をオフ → オンで再起動してペアリングをリセット
  • それでも繋がらない場合: Pocket 3 を長押し 8 秒で工場出荷設定にリセット後、再ペアリング
夜間撮影でノイズが多い
  • ISO を下げる（ISO 800 以下を目標に、シャッタースピードと ND を調整）
  • フレームレートを 24fps に下げて露光時間を稼ぐ（1/50 s → より多くの光を取り込む）
  • D-Log M で撮影し Resolve の Noise Reduction（Ultra NR）を適用
  • 補助光（LED ライト）の使用
バッテリーの持ちが短い
  • 4K/60fps・スローモーションは消費が大きい。用途に合わせて 4K/30fps に落とす
  • タイムラプスは特に消費が大きい → USB-C からの給電（モバイルバッテリー）を併用
  • 冬場は寒さでバッテリー性能が低下（気温 0°C で通常比 50〜60% 程度になる場合も）
  • Grip & Tripod Combo 経由でモバイルバッテリーを接続すると充電しながら撮影可能
MacBook で H.265 動画の編集が重い・コマ落ちする
  • M1 以降の Apple Silicon Mac は H.265 をハードウェアデコード。基本的に問題ない
  • Intel Mac の場合: DaVinci Resolve でプロキシ生成（Optimized Media / Proxy）を使用
  • H.264 で再撮影するか、ffmpeg で H.264 にバッチ変換してから編集
  • 編集ドライブが HDD の場合は SSD に変更するだけでも大幅改善
